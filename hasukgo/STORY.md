# 하숙생 맞고 — 이야기 정리

맞고 70% + 연애 비주얼노벨 30%. 하숙생 **열다섯 명 × 열 판 = 백오십 판**.

---

## 1. 세계관

바다가 보이는 언덕 위, **방 열다섯 개짜리 이층 별장**. 대문에는 삼십 년 된 나무 간판이 걸려 있다 — 「하숙」.

할머니는 이 좋은 집을 혼자 쓰지 않았다. 방을 하나씩 내줬다. 대학생, 갓 취직한 사람, 한 계절만 머물다 간 사람. 왜 하숙이냐고 물으면 늘 같은 대답이었다.

> 「집이 크면 사람이 있어야 해. 안 그러면 집이 먼저 늙는다.」

말년에는 **이층 뒤쪽 복도와 삼층 끝 두 방을 닫아두셨다.** 혼자 관리하기 벅차다는 이유였다. 지난봄 할머니가 돌아가시고, 집은 주인공에게 남았다. 반년 동안 이 집에서 나는 소리라고는 제 발소리와 유리에 부딪는 바람뿐이었다.

그런데 마루에는 아직 방석이 열 개 깔려 있다. 손님이 없는 날에도 할머니가 매일 저녁 펴두던 것이다. 그리고 마당 끝 별채에는 밤마다 불이 켜진다. 주인공은 아직 그 방에 누가 사는지 모른다.

**유지비를 감당하지 못해 다시 하숙을 놓는다.** 이것이 첫 화면의 이야기다.

### 첫 접속에 보는 것

| 순서 | 씬 | 내용 |
|---|---|---|
| 1 | `world` | 이 집에 대하여 — 바닷가 별장, 할머니, 닫아둔 방들 |
| 2 | `prologue` | 다시 하숙을 놓는 밤 — 삼월, 책상 위에 쌓인 고지서 |
| 3 | `eunseo_01` | 첫 하숙생 은서와의 첫 판 |

닫아둔 방이 하나씩 열리는 것이 곧 진행이다. 하숙생을 해금할 때마다 집이 되살아난다.

---

## 2. 규칙과 수위

- **판돈은 현금이 아니다.** 설거지 면제권·옥상 독점권 같은 **하숙집 포인트**다. 현금 결제·환전 기능이 전혀 없다.
- **연애는 이겨서 얻는 상이 아니다.** 승부를 계기로 서로 알아가다 상호 호감으로 이어지는 구조다. 모든 10단계 고백 대사에 이 취지가 명시돼 있다.
- 등장인물 전원 성인(22~29세). 인물 원화에 선정적 표현이 있어 **청소년 이용불가(18세)** 로 서비스한다.
- 살아 있는 어머니는 등장하지 않는다 — `tests/scripts.test.ts` 가 스크립트 전체에서 화자 '어머니'를 금지한다.

## 3. 한 사람을 공략하는 구조

열 단계가 하나의 호를 그린다. 판이 한 번 끝날 때마다 씬이 하나 열린다.

| 단계 | 역할 | 선택지 |
|---|---|---|
| 1 | 첫 만남 — 이 사람이 왜 이 집에 왔는가 | |
| 2 | 생활의 규칙 — 같이 사는 법을 배운다 | |
| 3 | 첫 마찰 또는 첫 부탁 | ✔ |
| 4 | **약점이 드러난다** — 이 사람이 숨기고 있던 것 | ✔ |
| 5 | 밖으로 나간다 — 집 밖에서 처음 만나는 장면 | ✔ |
| 6 | 그 사람의 일에 내가 끼어든다 | ✔ |
| 7 | 가장 안 좋은 날 — 아무것도 해결되지 않는다 | |
| 8 | 결정 전날 — 내가 무슨 말을 하는가가 중요해진다 | ✔ |
| 9 | 결과 — 좋든 나쁘든 혼자 겪지 않는다 | |
| 10 | **고백** — 엔딩 CG. 「이겨서 받는 상이 아니다」 | ✔ |

10단계를 넘기면 커플 모드로 다시 승부할 수 있다. 전원 10단계를 끝내면 숨겨진 엔딩 `hidden_ending`(마루의 단체 사진)이 열린다.

204·205·206·307·308 다섯 방이 **할머니가 닫아두셨던 방**이다. 진행하면서 하나씩 열린다.

### 해금 사슬

처음부터 열려 있는 사람은 **은서·하영·지우** 셋. 나머지는 앞선 누군가의 **5단계**를 넘겨야 열린다.

```
은서5 → 수아          하영5 → 민지, 세아
지우5 → 나래          수아5 → 예린, 가은
민지5 → 세연          나래5 → 도희, 하린
예린5 → 다빈          세연5 → 나윤
예린5 + 세연5 + 도희5 → 윤
```

## 5. 난이도

실력은 세 축으로만 만든다. 승률을 실제로 움직이는 것만 남겼다.

- **mistakeRate** — 판을 안 보고 아무 패나 내는 빈도. 가장 큰 축
- **inference** — 바닥에 깔면 상대가 가져간다는 걸 아는가. 고를 질렀을 때 뒤집힐 위험이 보이는가
- **greed** — 이겼는데도 더 가는가. **초보는 지르고 고수는 접는다.** 고는 점수를 걸고 하는 거래라 욕심이 곧 약점이 된다

흔들기·폭탄과 점수 항목 취향은 승패보다 판돈과 스타일에 영향을 준다. 난이도 축이 아니라 성격이다.

숙련 플레이어 기준 사다리: **세아 1단계 85% → 윤 10단계 49%**. `tests/tenants.test.ts` 가 이 사다리(양끝 30%p 이상, 하숙생별 1→10단계 단조)를 못으로 박고 있다.

## 6. 파일이 어디 있나

| 무엇 | 어디 |
|---|---|
| 하숙생 데이터 · 대사 | `src/data/tenants.json` |
| 시나리오 대본 | `src/data/scripts/{id}.txt` (+ `common.txt`) |
| 대본 문법 | `src/scenario/parser.ts` |
| 인물 원화 | `public/art/char/{id}[_face][_표정].webp` |
| 난이도 곡선 | `src/ai/params.ts` |

대본 문법은 이렇게 생겼다.

```
=== sea_01 | 새벽 다섯 시의 발소리
@bg hallway night
@bgm spring
@outfit 0
* 지문은 별표로 시작한다.
세아 [놀람] 어! 깨셨어요?
나 [기본] 지금 다섯 시인데요.
@choice
- 첫 번째 선택 | +15 | A
- 두 번째 선택 | +15 | B
@label A
...
@goto END
@label B
...
@label END
@affection 10
@end
```

데이터를 고치면 `npm test` 가 먼저 걸린다 — scriptId 존재, 이벤트당 대사 다섯 줄 이상, 10단계 엔딩 CG, 호감도 상승, 분기 무한루프 없음, 건너뛰기 동치성까지 검사한다.

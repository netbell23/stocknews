# 🥾 두마음 산악회

트랭글·스트라바 스타일의 **산행 안내·GPS 기록 모바일 웹앱** + **산행자 단톡(그룹채팅)** 기능.
설치 없이 브라우저로 바로 쓰는 PWA(휴대폰 홈화면에 추가 가능).

## 기능

| 탭 | 내용 |
|----|------|
| 🏠 **홈** | 접속 시 첫 화면. **달력**(다녀온 산행·예정된 일정을 점으로 구분 표시, 탭하면 그날 상세, 월 이동) + **산행 일정 등록/참여**(회원간 공유, 아래 참고) + 최근 다녀온 산 목록, 이번 달 산행 횟수 등 요약 |
| 🗺️ **지도** | 실시간 GPS 위치, 등고선/일반 지도 전환, **산행 기록(시작·일시정지·종료)** — 거리·시간·페이스·누적상승 실시간 계산 및 경로 그리기. **화면이 꺼지거나 앱이 정리돼도 기록이 끊기지 않도록 진행 중인 경로를 계속 저장**, 다시 열면 자동으로 이어서 기록(6시간 넘게 끊겼으면 확인 후 진행) |
| 📊 **기록** | 저장한 산행 목록·누적 통계, 상세 보기(경로 지도 + **고도 프로필 차트**), 단톡 공유, 백업 내보내기 |
| ⛰️ **산안내** | 산림청 선정 **100대 명산** + 청계산·아차산 등 **인기 등산 코스 15곳** + **회원이 직접 등록한 산**까지 전부 검색 가능. 이름·지역 검색 + 난이도 필터, 목록에 없는 산은 바로 등록 가능 |
| 🏅 **완등맵** | 아임매퍼처럼 **100대 명산만 지도에서 스크래치되어 드러나는** 완등 지도(진행률 N/100). 🔍 검색 체크리스트에서는 100대 명산 외 인기 코스·회원 등록 산도 함께 검색해서 다녀왔다고 체크할 수 있음(단, 완등맵 진행률·뱃지에는 포함 안 됨) |
| 💬 **단톡** | 단톡방 생성·채팅, **현재 위치 공유**, **산행 기록 공유**, 안 읽은 메시지 배지 |
| 👤 **내정보** | **Google/Apple 로그인 또는 게스트** 선택(첫 방문 시), **계급(1~100단계) · 뱃지 13종 · 회원간 실시간 랭킹**, 프로필(닉네임·색상), 누적 통계, 지도 설정 |

## 실행 방법

> ⚠️ GPS(위치)와 카메라 등은 보안상 **`https://` 또는 `localhost`** 에서만 동작합니다.
> `index.html`을 파일로 바로 열면(`file://`) 위치 기능이 막힐 수 있으니 아래처럼 **서버로 띄워** 주세요.

### 1) 가장 쉬운 방법 (권장) — Node.js
```powershell
cd D:\git\stocknews\hiking-app
node server.js
```
- 정적 파일 서빙 + **단톡 실시간 중계(WebSocket)** 까지 한 번에 됩니다.
- 실행하면 콘솔에 `http://192.168.x.x:8787` 같은 주소가 뜹니다.
  같은 와이파이의 **휴대폰 브라우저에서 그 주소로 접속**하면 진짜 모바일에서 GPS로 기록됩니다.
- 여러 사람이 같은 주소로 접속하면 **단톡이 실시간으로** 연결됩니다.

### 2) Node가 없으면 — 자동 분기 스크립트
```powershell
cd D:\git\stocknews\hiking-app
./start.ps1
```
Node가 있으면 통합 서버, 없으면 Python 정적 서버(`python -m http.server 8787`)로 실행합니다.
(Python 정적 서버는 단톡이 **로컬 모드**로만 동작 — 같은 기기/브라우저 탭끼리만 동기화)

### 휴대폰 홈화면에 앱처럼 추가
접속 후 브라우저 메뉴 → "홈 화면에 추가" → 전체화면 앱으로 실행됩니다.

### 뒤로가기 버튼
폰의 시스템 뒤로가기(또는 브라우저 뒤로가기)를 누르면 앱을 벗어나지 않고 **바텀시트 → 단톡방 → 이전 탭** 순서로 한 단계씩 되돌아갑니다. History API(`pushState`/`popstate`)로 구현돼 있습니다.

## 단톡 동작 방식
- **서버(`server.js`) 실행 중**: WebSocket으로 접속자 간 메시지가 **실시간 중계**됩니다(서로 다른 폰끼리 OK).
- **서버 없이 정적 호스팅**: 같은 브라우저의 탭 간(BroadcastChannel/localStorage)에서만 동기화되는 **로컬 모드**.
  단톡 탭 상단의 연결 상태 표시로 현재 모드를 확인할 수 있습니다.

## 로그인 (Google/Apple) · 랭킹(Firestore) 설정
게스트 모드는 설정 없이 바로 됩니다. Google 로그인과 회원간 랭킹을 켜려면 `firebase-config.js` 파일을 열어 안내된 순서대로 본인 Firebase 프로젝트 값(무료)을 채워 넣고, 파일에 적힌 Firestore 보안 규칙을 그대로 붙여넣으세요. Apple 로그인은 Apple Developer Program 유료 가입($99/년)이 추가로 필요하며, 설정 절차도 `firebase-config.js`에 안내돼 있습니다 — 설정 전에는 버튼을 눌러도 안내만 뜨고 앱은 정상 동작합니다.

## 계급 · 뱃지 · 랭킹
- **계급**: 누적 산행 거리 기준 1~100단계. 구간마다(새싹 산꾼 → 도전하는 산꾼 → 능선 등반가 → 베테랑 산악인 → 명산 마스터 → 그랜드마스터 → 산신령) 다음 계급까지 필요한 거리가 늘어나요.
- **뱃지**: 산행 횟수, 100대 명산 완등 개수, 3대 명산(한라·지리·설악) 완등, 누적 거리(마라톤·100km·500km), 누적 상승고도(에베레스트 높이) 등 13종. 완등맵·기록과 자동 연동됩니다.
- **랭킹**: 내정보 탭 "🏆 랭킹" 버튼에서 전체 회원의 누적 거리 순위를 볼 수 있어요. Firestore 설정 전에는 안내만 표시됩니다.

## 산행 일정 (예약 + 참여 태그)
- 홈 탭 캘린더 아래 **"📅 산행 일정 만들기"**로 날짜·시간·산 이름·메모를 넣어 일정을 등록하면 **회원 전체에게 공유**됩니다.
- 캘린더에서 예정된 일정은 파란 점, 다녀온 산행 기록은 빨간 점으로 구분 표시됩니다.
- 일정을 탭하면 참여자 아바타 목록과 **"🙋 참여하기"** 버튼이 뜨고, 눌러서 참여를 태그하거나 취소할 수 있어요.
- 일정을 만든 사람만 삭제할 수 있습니다. Google/Apple/게스트 모두(로그인만 되어 있으면) 만들기·참여 둘 다 가능합니다.
- Firestore 설정 전에는 "설정 전이에요" 안내만 뜨고 나머지 기능은 정상 동작합니다.

## 산 목록 (100대 명산 + 인기 코스 + 회원 등록)
- **100대 명산 100곳**: 완등맵 진행률·뱃지·랭킹의 기준이 되는 공식 목록(안 바뀜).
- **인기 코스 15곳**: 청계산·광교산·아차산·인왕산·안산·우면산·대모산·용마산·수락산·불암산·검단산·남한산·예봉산·운길산·장산(부산) 등 100대 명산엔 없지만 자주 찾는 도심 근교 산. 산안내·완등맵 검색·체크에서 보이고 "인기 코스" 표시가 붙습니다.
- **회원 등록 산**: 산안내나 완등맵 검색에서 **"➕ 목록에 없는 산 등록하기"**로 누구나 추가 가능. Firestore가 설정돼 있으면 다른 회원도 바로 검색할 수 있고(공유), 설정 전이면 이 기기에만 저장됩니다. GPS가 켜져 있으면 현재 위치가 좌표로 같이 등록돼요.
- 인기 코스·회원 등록 산은 완등맵의 "N/100" 진행률과 "100대 명산 완주" 뱃지 계산에는 포함되지 않습니다(공식 100대 명산 컬렉션의 의미를 지키기 위해 의도적으로 분리).

## 기술
- 지도: [Leaflet](https://leafletjs.com) + OpenStreetMap / OpenTopoMap (API 키 불필요)
- 위치: 브라우저 Geolocation `watchPosition` (고정밀)
- 저장: `localStorage` (기기 내 저장)
- 서버: Node 내장 모듈만 사용 (외부 의존성 0개) — 정적 서빙 + 최소 WebSocket 구현
- PWA: `manifest.json` + `sw.js`(앱 셸 오프라인 캐시)

## 한계 / 참고
- GPS 고도는 기기·신호에 따라 오차가 큽니다(누적상승은 노이즈 필터를 적용했지만 참고용).
- 산 코스 거리·시간은 참고값입니다. 기상·입산 통제는 [국립공원공단](https://www.knps.or.kr) 확인 필수.
- 데이터는 기기에 저장되므로, 기기를 바꾸면 "내보내기"로 백업하세요.
- **게스트 모드는 기기(브라우저)에 묶인 신원**입니다 — 같은 폰이라도 브라우저 앱을 바꾸거나(예: 카카오톡 인앱브라우저 ↔ 크롬) 사이트 데이터를 지우면 다른 사람으로 인식됩니다. 여러 기기·브라우저에서 같은 계정으로 알아보게 하려면 Google/Apple 로그인을 쓰세요.
- 산행 중 GPS 트래킹은 **화면이 켜져 있고 이 앱이 화면에 떠 있을 때** 가장 안정적입니다. 화면을 오래 꺼두거나 다른 앱을 오래 쓰면 iOS/Android가 위치 갱신을 멈추거나 탭을 정리할 수 있습니다(브라우저/OS 자체 제약, 앱에서 완전히 막을 수는 없음) — 대신 지금까지 기록된 경로는 저장돼 있다가 다시 열면 자동으로 이어집니다.

# 🥾 두마음 산악회

트랭글·스트라바 스타일의 **산행 안내·GPS 기록 모바일 웹앱** + **산행자 단톡(그룹채팅)** 기능.
설치 없이 브라우저로 바로 쓰는 PWA(휴대폰 홈화면에 추가 가능).

## 기능

| 탭 | 내용 |
|----|------|
| 🗺️ **지도** | 실시간 GPS 위치, 등고선/일반 지도 전환, **산행 기록(시작·일시정지·종료)** — 거리·시간·페이스·누적상승 실시간 계산 및 경로 그리기 |
| 📊 **기록** | 저장한 산행 목록·누적 통계, 상세 보기(경로 지도 + **고도 프로필 차트**), 단톡 공유, 백업 내보내기 |
| ⛰️ **산안내** | 산림청 선정 **100대 명산** 전체의 코스·난이도·소요시간 정보, 지도 위치 보기 |
| 🏅 **완등맵** | 아임매퍼처럼 **다녀온 산만 지도에서 스크래치되어 드러나는** 완등 지도. 산행 기록(GPS 반경 5km 이내 또는 기록 이름 일치)을 기준으로 자동 판정, 완등률 진행바 표시 |
| 💬 **단톡** | 단톡방 생성·채팅, **현재 위치 공유**, **산행 기록 공유**, 안 읽은 메시지 배지 |
| 👤 **내정보** | **Google 로그인 또는 게스트** 선택(첫 방문 시), 프로필(닉네임·색상), 누적 통계, 지도 설정 |

## 실행 방법

> ⚠️ GPS(위치)와 카메라 등은 보안상 **`https://` 또는 `localhost`** 에서만 동작합니다.
> `index.html`을 파일로 바로 열면(`file://`) 위치 기능이 막힐 수 있으니 아래처럼 **서버로 띄워** 주세요.

### 1) 가장 쉬운 방법 (권장) — Node.js
```powershell
cd D:\git\stocknews\hiking-app
node server.js
```
- 정적 파일 서빙 + **단톡 실시간 중계(WebSocket)** 까지 한 번에 됩니다.
- 실행하면 콘솔에 `http://192.168.x.x:8787` 같은 주소가 뜹니다.
  같은 와이파이의 **휴대폰 브라우저에서 그 주소로 접속**하면 진짜 모바일에서 GPS로 기록됩니다.
- 여러 사람이 같은 주소로 접속하면 **단톡이 실시간으로** 연결됩니다.

### 2) Node가 없으면 — 자동 분기 스크립트
```powershell
cd D:\git\stocknews\hiking-app
./start.ps1
```
Node가 있으면 통합 서버, 없으면 Python 정적 서버(`python -m http.server 8787`)로 실행합니다.
(Python 정적 서버는 단톡이 **로컬 모드**로만 동작 — 같은 기기/브라우저 탭끼리만 동기화)

### 휴대폰 홈화면에 앱처럼 추가
접속 후 브라우저 메뉴 → "홈 화면에 추가" → 전체화면 앱으로 실행됩니다.

## 단톡 동작 방식
- **서버(`server.js`) 실행 중**: WebSocket으로 접속자 간 메시지가 **실시간 중계**됩니다(서로 다른 폰끼리 OK).
- **서버 없이 정적 호스팅**: 같은 브라우저의 탭 간(BroadcastChannel/localStorage)에서만 동기화되는 **로컬 모드**.
  단톡 탭 상단의 연결 상태 표시로 현재 모드를 확인할 수 있습니다.

## 로그인 (Google) 설정
게스트 모드는 설정 없이 바로 됩니다. Google 로그인을 켜려면 `firebase-config.js` 파일을 열어 안내된 순서대로 본인 Firebase 프로젝트 값(무료)을 채워 넣으세요.

## 기술
- 지도: [Leaflet](https://leafletjs.com) + OpenStreetMap / OpenTopoMap (API 키 불필요)
- 위치: 브라우저 Geolocation `watchPosition` (고정밀)
- 저장: `localStorage` (기기 내 저장)
- 서버: Node 내장 모듈만 사용 (외부 의존성 0개) — 정적 서빙 + 최소 WebSocket 구현
- PWA: `manifest.json` + `sw.js`(앱 셸 오프라인 캐시)

## 한계 / 참고
- GPS 고도는 기기·신호에 따라 오차가 큽니다(누적상승은 노이즈 필터를 적용했지만 참고용).
- 산 코스 거리·시간은 참고값입니다. 기상·입산 통제는 [국립공원공단](https://www.knps.or.kr) 확인 필수.
- 데이터는 기기에 저장되므로, 기기를 바꾸면 "내보내기"로 백업하세요.
